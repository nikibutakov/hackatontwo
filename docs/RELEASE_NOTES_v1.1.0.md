# v1.1.0 — финальный релиз

Завершающая версия проекта «PCB Defect Inspector» — сервиса контроля качества
печатных плат (хакатон «Осенний Хакатон 2026», задание 4).

## Модели

- **Своя v2** (`pku-dspcbsd-merged-yolov8s`, активная): 10 классов на
  объединении PKU + DsPCBSD+ (14 587 изображений), mAP@0.5 0.927,
  precision 0.978 — вдвое меньше ложных срабатываний против v1.
- **Своя v1** (`pku-yolov8s-ours`): 6 классов, mAP@0.5 0.944 — лучший
  результат на классах дорожек.
- Четыре бейзлайна с Hugging Face, включая YOLO26 (2025) — использована для
  бенчмарка и доказательства утечки данных в чужой валидации.

## Что внутри

- Анализ фото: детекции + вердикт «годен / проверка / брак» + чек-лист ТЗ.
- Живая камера: стабилизированный real-time поток (подтверждение по кадрам,
  IoU-треки, EMA), адаптивный размер кадра, 2 кадра в пути при сетевом упоре.
- Демо-инфраструктура: сторож-сервер, автозагрузка, Tailscale HTTPS-туннель
  с запасным каналом Cloudflare, предполётная проверка стенда, режим
  «видео-файл».
- 43 автотеста, Swagger, полная документация (API, архитектура, CHANGELOG,
  сценарий выступления, Q&A жюри), презентация на 8 слайдов.

## Метрики честности

Валидация всех наших моделей — board-disjoint (платы, не встречавшиеся при
обучении). Контр-пример: готовая YOLO26 даёт 0.995 на этой же выборке из-за
обучения на тех же платах; её честный тест — 0.839. Воспроизведение:
`python ml/bench_val.py` и `python ml/bench_boards.py`.

- `run_demo.bat` — предполётная проверка + сервер на реальных моделях.
