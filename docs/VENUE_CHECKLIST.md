# Чек-лист дня Х: сервер на домашнем ПК, показ с ноутбука

Домашний ПК (RTX 3050) — инференс-сервер. Ноутбук на площадке — браузер.
Удалённые руки: AnyDesk с ноутбука на домашний ПК.

## Уже сделано на домашнем ПК

- [x] `run_server.bat` — запуск сервера с автоперезапуском при падении
- [x] Ярлык в автозагрузке (сервер стартует при входе в Windows)
- [x] Сон и гибернация выключены
- [x] `tools/cloudflared.exe` — запасной туннель (качать на площадке уже не надо)
- [x] torch 2.9.1 — баг с падением сохранения чекпойнтов не актуален

## Сделать ДО площадки (Никита, за домашним ПК, ~40 минут)

- [ ] **Tailscale на ПК**: установить (tailscale.com), вход через Google.
      В админке login.tailscale.com включить **MagicDNS** и **HTTPS Certificates**
      (вкладка DNS, две галки).
- [ ] Запустить туннель: в PowerShell `tailscale serve --bg http://localhost:8000`.
      Записать выданный URL вида `https://<имя-пк>.<tailnet>.ts.net` —
      это главный адрес демо. Он же решает проблему камеры (HTTPS).
- [ ] **Тест с телефона** (заменяет недоступный ноутбук): Tailscale на телефоне
      под тем же аккаунтом → открыть URL в браузере телефона → вкладка «Фото»
      (примеры работают) и вкладка «Живая камера» (камера телефона, навести на
      фото платы на мониторе). Если оба прошли — связка готова.
- [ ] **AnyDesk на ПК**: установить ЗАПУСТИВ УСТАНОВЩИК ОТ АДМИНИСТРАТОРА
      (тогда служба стартует до входа в систему — переживёт ребут без логина),
      задать постоянный пароль (Настройки → Безопасность), выписать 9-значный ID.
      Проверить подключение с телефона хотя бы раз.
- [ ] **Windows Update**: Параметры → Центр обновления → приостановить на 7 дней.
- [ ] **Автовход Windows** (по желанию, но рекомендую): `netplwiz` → снять
      «Требовать имя пользователя и пароль» — после ребута сервер поднимется сам.
- [ ] **Записать резервное видео полного демо через OBS** (фото → камера →
      переключение моделей → метрики), 3–5 минут, пока всё стабильно работает.
- [ ] **Подготовить флешку для ноутбука**: клон репозитория + `ml/weights/*.pt`
      (5 файлов, ~150 МБ) + записанное видео. Это «последний рубеж».

## На площадке (15 минут до выхода на сцену)

1. Ноутбук: AnyDesk → домашний ПК → убедиться, что окно `run_server.bat`
   живо (лог запросов идёт). Быстрый чек: на самом ПК открыть
   `http://localhost:8000/api/health` — `"active_model": "pku-dspcbsd-merged-yolov8s"`.
2. Ноутбук: поставить Tailscale, тот же аккаунт → открыть демо-URL.
3. Проверка: зелёная точка в шапке, модель в селекторе, вкладка «Фото»
   (пример `10_open_circuit` → «Брак: разрыв дорожки»), вкладка «Камера»
   (веб-камера ноутбука + распечатка).
4. Прогреть модели переключением (каждая грузится при первом обращении).

## Если что-то не работает (лестница запасных сценариев)

| Симптом | Действие |
|---|---|
| Ноут не видит `ts.net`-адрес | Раздать интернет с телефона (хотспот) и повторить |
| Tailscale заблокирован сетью площадки | Через AnyDesk на ПК запустить `E:\Hackaton\tools\cloudflared.exe tunnel --url http://localhost:8000` — выдаст `https://xxx.trycloudflare.com`, открыть на ноуте (клиент не нужен) |
| Домашний ПК недоступен вовсе | Флешка: локальный запуск на ноуте (CPU) — `pip install -r requirements.txt -r ml/requirements-ml.txt` + веса; вкладка «Фото» и «видео-файл» работают |
| Всё умер | Запасное видео с флешки |
