# Примеры фото для демо

Картинки из этой папки появляются миниатюрами под зоной загрузки на вкладке
«Фото» — анализ в один клик, без поиска файлов по диску.

Что сюда класть:

- 3–5 снимков плат (JPEG/PNG/WEBP/BMP), на которых модель **уверенно** находит
  дефекты — те же, что распечатаны для демо;
- желательно хотя бы одну **чистую** плату (вердикт «ГОДЕН») и одну с разрывом
  дорожки (покажет пункт ТЗ «Разрыв на дорожках платы»);
- имена файлов — понятные, они видны под миниатюрой (`01_razryv.jpg`, `02_nepropay.jpg`);
- до ~1 МБ на файл, чтобы репозиторий не разбухал.

Порядок миниатюр — по имени файла. Подпапки не читаются.
API: `GET /api/examples` (список), `GET /api/examples/{name}` (картинка).
